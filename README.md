# AI Agents See Security Website

Professional, responsive multi-page website for **AI Agents See Security**, designed for SMB audiences and focused on the primary conversion:

- Request a Security Assessment

Secondary conversion:

- Book a Consultation

## Project structure

- `assets/css/styles.css` – shared design system and responsive styles
- `assets/js/main.js` – mobile nav, footer year, reveal animations
- `*.html` – all requested pages
- `server.js` – local static server
- `tests/smoke.mjs` – basic smoke test for all pages and key CTA text

## Run locally

```bash
npm start
```

Then open:

- `http://localhost:8080`

## Run smoke tests

```bash
npm test
```
